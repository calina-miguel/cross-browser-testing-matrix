# Summit Cycle Works Browser QA Matrix

Build a browser compatibility QA matrix for Summit Cycle Works, an ecommerce cycling brand reviewing storefront releases across browsers, devices, input modes, and accessibility settings. The interface should support fast scanning, filtering, and release risk review.

Use a responsive React front-end suitable for Vercel deployment. The first screen should show the Summit Cycle Works QA matrix title, compatibility summary metrics, and filter controls for desktop, mobile, and accessibility scenarios.

Required features:

- Compatibility matrix with Chrome, Safari, Firefox, and Edge columns.
- Scenario rows for responsive collection grid, sticky add-to-cart, CSS fallback behavior, keyboard focus order, reduced motion, and mobile viewport units.
- Filters for All, Desktop, Mobile, and Access.
- Status states for Pass, Review, and Blocked.
- Summary panel showing total scenarios, passed scenarios, review items, and release confidence.
- Notes area for browser-specific findings.
- Responsive behavior for narrow screens.
- Accessible controls with visible focus states and text labels for status indicators.

Visual direction:

- QA and engineering operations feel.
- Cool neutral surfaces, high-contrast table states, blue/teal primary controls, amber review signals, and red blocked signals.
- Dense but readable matrix design.
- Avoid decorative marketing sections.

Do not include wording that describes the work as a sample, prototype, template, demo, portfolio, test, generated output, or artificial intelligence assisted work.
